# Araç referans görselleri

Proje sahibinin ChatGPT ile ürettiği tepeden bakış çizimleri. Bunlar oyuna
DOĞRUDAN GİRMEZ — oyundaki araçlar `game/CarCatalog.kt` içinde geometri
olarak duruyor (9 boyanın hepsiyle çizilebilmesi için). Buradaki dosyalar
o geometriyi çıkarmak için REFERANS.

Dosya adı şu şekilde olsun ki hangi gövdeye ait olduğu belli olsun:

- `kus_slx.png`        → petrol/teal sedan
- `dag_kecisi.png`     → beyaz station wagon
- `boga67.png`         → siyah + beyaz çift şeritli kas arabası

İstenen biçim: PNG, saydam zemin, tepeden (ortografik) bakış, burun yukarı,
simetrik, gölgesiz. 1024x1024 tuvalde araç ~500x950 px.
